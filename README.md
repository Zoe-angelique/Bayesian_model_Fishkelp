# Bayesian FishKelp model

This repository contains Zoë-Angelique Petersen's Bayesian framework and a
portable snapshot of the FishKelp v7 data for all 30 fish listed in Table 2 of
Blamey and Bolton (2018).

Start with
[`Bayesian_framework/FishKelp_full_species_suite.qmd`](Bayesian_framework/FishKelp_full_species_suite.qmd).
AJ wrote that document as the main instructional analysis for Zoë. It explains
the data and gives the run order for the complete species suite.

The packaged data are documented in
[`data/fishkelp_v7/README.md`](data/fishkelp_v7/README.md).
